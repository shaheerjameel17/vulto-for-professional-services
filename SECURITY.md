# Security Policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately, using the **Report a vulnerability** button under this repository's **Security** tab (GitHub private vulnerability reporting). Do not open a public issue or pull request for a security problem.

Include what you found, steps to reproduce it, the affected commit, and the impact you expect. Reports are read and answered on a best-effort basis; no response-time guarantee is offered at this stage.

## Scope and status

This repository is under active development. It has no production deployment and holds no customer data. Fixtures and sample data are fictional. Design intent, including known gaps, is documented in `docs/Vulto_Specs/` and recorded in `docs/Foundations_Findings.md`.

## Coordinated disclosure

Please give us a reasonable time to fix an issue before disclosing it publicly, and avoid accessing or exposing data that is not yours while testing.
