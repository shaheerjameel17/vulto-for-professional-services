The schema test even pins `FEATURE_LIFECYCLE_NODE_TYPES.has("Entity")` to true. None of these paths changed in this stage. A separate two-tabs browser assertion also failed after the suite's other failures; it has not been diagnosed because the core contradiction already requires a stop.
