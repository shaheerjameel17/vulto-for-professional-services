### F328 — LeavePolicy resolves to none for Manager and Team Member under the Standard default

**Found while:** briefing Stage 27 (`VRS-F018`), 26 September 2026, by checking the spec against the code before writing the brief.

`LeavePolicy` is registered `Standard` Tier 0, and the `Standard` class default gives Manager `Full (direct reports)` and Team Member `Read (own + team)`. Those scopes resolve through a subject Employee, and a policy has none, so under F128's rule (any scope other than `any` resolves to `none`) a Manager and a Team Member can read no policy at all, contradicting the spec ("every role reads policies; only Owner and HR Admin write, per the workspace-configuration pattern").

**Files:** `packages/schema/src/policy/policy-table.ts`, `docs/Vulto_Specs/VPS-A004_Graph_Permission_Layer.md`, `docs/Vulto_Specs/VRS-F018_Leave_Policy_Engine.md`

**Ruling.** **Closed 26 September 2026 by ruling.** `LeavePolicy` gets a matrix override row identical to `WorkingCalendar`'s (the workspace-configuration pattern that already exists): Owner and HR Admin `full` any, Finance Admin, Manager and Team Member `read` any. The fidelity test keeps reading the literal matrix. This is the only permission-layer change in Stage 27.
