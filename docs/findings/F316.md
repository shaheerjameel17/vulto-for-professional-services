### F316 — the pipeline hook cannot see the rows the watched engines write

**Found while:** Codex tracing Stage 25 Do item 3 before writing product code, 26 September 2026 (stage report `10ad231`); ruled by the reviewer the same day.

The F308 ruling routed delivery through the mutation pipeline's `applied.changedRowIds`, but the two watched rows are never in it. `timesheet.ts:290` awaits the anomaly engine after commit and discards its `{ flagIds }`; `timesheet-anomaly.ts:275–291` creates flags in its own `db.transaction`; `revenue-gap-alert.ts:231–248` creates and escalates alerts in its own transaction, invoked from `assignment.ts` afterCommit callbacks (`:402`, `:652`, `:699`) that discard the alert ids; `revenueGapAlert.sweep` (`router.ts:435`) never enters `applyMutation` at all; and the anomaly flag (Tier 2) never calls `audienceMaterializer.onRowsChanged`, so that seam is not universal either. A hook on `changedRowIds` would deliver nothing for either shipped rule, and a test that hands `deliverForRows` an id would prove nothing about production. The reviewer had traced the pipeline's signal but not the writers.

**Files:** `services/api/src/mutations/pipeline.ts`, `services/api/src/mutations/timesheet.ts`, `services/api/src/mutations/timesheet-anomaly.ts`, `services/api/src/mutations/revenue-gap-alert.ts`, `services/api/src/mutations/assignment.ts`, `services/api/src/router.ts`, `services/api/src/graph/store.ts`

**Ruling.** **Closed 26 September 2026 by ruling.** The one place every graph write already passes is the store's write functions, so the signal is taken there: a new `graph/write-log.ts` (`AsyncLocalStorage`-scoped set of written node and edge ids) fed by one additive `recordWrite` call in each store write function, drained after success by `withNotificationDelivery`, which wraps the whole of `applyMutation` (so `afterCommit` and the standalone engines inside it are covered) and every tRPC procedure through one generic middleware in `trpc.ts` (so the sweep is covered). Delivery's own writes run with the scope cleared. Ids from rolled-back or retried transactions point at absent rows and are skipped. No source feature file changes (G03). Tests must prove delivery through the real paths (`timesheet.submitWeek`, an assignment change, the sweep), never by handing the engine an id. At-least-once after a crash between commit and drain remains for the jobs service's reconciliation (F308). Lesson: trace the writers, not only the pipeline's signal, before promising a hook can see their rows.
