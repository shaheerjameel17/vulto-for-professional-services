### F355 — Documents (`VRS-F022`) is unbuilt anywhere in the codebase

**Found while:** briefing UI-2, 27 September 2026.

`DocumentsTab.tsx` already renders the correct empty state ("No documents uploaded yet.") when `profile.documents.length === 0`, but nothing produces a non-empty case to check it against: a `Document` node type appears only in `packages/schema/src/registry.test.ts`, with no real schema file, mutation, query, storage adapter or encryption path anywhere in the repository, despite `VPS-A002`'s registry table listing `VRS-F022` (Encrypted Document Vault) as its owner. This is a genuinely unbuilt forward dependency, not a documentation gap like F296 — no ruling anywhere has closed it before.

**Files:** `apps/roster-web/src/components/profile/DocumentsTab.tsx`, `packages/schema/src/registry.test.ts`, `docs/Vulto_Specs/VRS-F022_Encrypted_Document_Vault.md`, `docs/Vulto_Specs/VPS-A002_Master_Graph_Schema_Definition.md`

**Ruling.** **Closed 27 September 2026 by ruling.** The Documents tab is wired to real (currently empty) data — a local query that will find zero rows because the node type does not exist to populate it — never a fixture. It renders its already-correct empty state honestly, from nothing, exactly as written today. `VRS-F002`'s Out of Scope section gains a line naming `VRS-F022` as the reason, matching how it already handles Performance history, Background checks and the org chart.
