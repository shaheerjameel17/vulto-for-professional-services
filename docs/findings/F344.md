### F344 — the palette's specified groups outrun the index

**Found while:** briefing UI-1, 27 September 2026.

The palette component has seven groups (Commands, People, Skill matches, Projects, Clients, Documents, Policies), but the local index covers only `Employee`, `Skill`, `Project` and `Client` (`SEARCHABLE_NODE_TYPES`), `Document` and `Policy` are unbuilt, and two of the six static commands are actions (`employee.create`, `assignment.create`) whose surfaces may not be wired to the real client.

**Files:** `packages/graph/src/queries/search.ts`, `packages/graph/src/queries/search-commands.ts`, `packages/ui/src/CommandPalette.tsx`

**Ruling.** **Closed 27 September 2026 by ruling.** The palette renders only groups that have results, so Documents and Policies never appear as empty headers, and the empty state is one identical message whether nothing matched or matches were filtered (`VPS-F002`: no oracle). A person's context line is their availability and next roll-off date (`availabilityStatus`, `nextRolloffDate` from the result), a skill's is its category. A `navigate` command opens its route through the router; an `action` command is offered only if its target surface exists on the real client, otherwise it is omitted from the results rather than shown dead (the builder traces each and reports which). Role-aware command visibility stays a later concern (F300).
