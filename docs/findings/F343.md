### F343 — the sidebar count and the palette are still prototype scaffolding

**Found while:** briefing UI-1, 27 September 2026.

`apps/roster-web/src/nav.ts` hard-codes `count: 7` on the Inbox item and `Shell.tsx` feeds the palette from `fixtures/command-palette.ts`. Both were the prototype's mocks; the Shell already mounts the real graph client (`FDN-117`), so they are the last two fixture dependencies of the shell itself.

**Files:** `apps/roster-web/src/nav.ts`, `apps/roster-web/src/components/Shell.tsx`, `apps/roster-web/src/fixtures/command-palette.ts`

**Ruling.** **Closed 27 September 2026 by ruling.** The count is supplied at runtime from `notification.unreadActionCount` and hidden at zero (`VPS-D004`: a count only where it implies an action); `NAV_GROUPS` keeps no static count. The shell stops importing `fixtures/command-palette.ts` and it is deleted if nothing else imports it (report what does). Other prototype screens keep their fixtures; this stage retires only the shell's two.
