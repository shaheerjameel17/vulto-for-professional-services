### F333 — the specified local, offline queries cannot be built yet

**Found while:** briefing Stage 27 (`VRS-F018`), 26 September 2026, by checking the spec against the code before writing the brief.

`leaveBalance.compute` and `leavePolicy.getApplicable` are specified as local, offline queries (200 ms and 20 ms), but a local balance needs entity and jurisdiction resolution and `LeaveRequest` rows on the device, and neither exists in `packages/graph` (`resolveForEmployee` is server-side; Stage 11 built it there).

**Files:** `services/api/src/graph/entity-resolution.ts`, `packages/graph/src/queries/`

**Ruling.** **Closed 26 September 2026 by ruling.** The engine is pure and dependency-injected so a local adapter is a small later step, but Stage 27 builds the server queries only, and the 200 ms and 20 ms figures are measured and reported server-side, not asserted as offline guarantees. The local query ships with `VRS-F019`, when there is a balance surface and replicated requests to compute over.
