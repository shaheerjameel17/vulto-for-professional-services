### F332 — LeaveRequest has no schema for balance usage to read

**Found while:** briefing Stage 27 (`VRS-F018`), 26 September 2026, by checking the spec against the code before writing the brief.

A balance's `used` comes from "approved request history", but `LeaveRequest` has no field schema (registered only, owner `VRS-F019`, unbuilt), so `VRS-F018` cannot read approved requests and must not invent `VRS-F019`'s schema.

**Files:** `packages/schema/src/registry/nodes.ts`, `docs/Vulto_Specs/VRS-F019_Self-Service_Leave_Portal.md`

**Ruling.** **Closed 26 September 2026 by ruling, on the forward-dependency precedent (F299, F296).** The pure engine takes usage as an input list of `{ leave_type, start_date, end_date }` (approved requests, dates inclusive). The server balance query passes an empty list until `VRS-F019` defines `LeaveRequest`, and the stage reports that plainly; the tests inject usage. `VRS-F019` connects the real reader when it lands.
