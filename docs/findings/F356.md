### F356 — Activity has no real business-event source; `VPS-F004`'s audit log is the wrong feed and would be a category error

**Found while:** briefing UI-2, 27 September 2026.

`ActivityTab.tsx` already renders the correct empty state ("Nothing recorded yet.") when `profile.activity.length === 0`. The one real, built event log in the codebase is `VPS-F004`'s audit log (`auditLog.query`, backed by `queryAuditLog`), but its `AUDIT_EVENT_TYPES` — `PermissionDenied`, `SensitiveAccessGranted`, `AuthorizedOperationFailed`, `PrivilegedProjectionAuthorized`, `CryptographicErasureExecuted` — are a security and compliance trail (VPS-A008's trust program): refusals, protected-data access grants and erasure events, not "what happened to this person" in any ordinary sense (a promotion, a status change, a note added). Its query schema also has no `target_node_id` filter, so it cannot even be scoped to one employee without a broader change. Wiring Activity to it would render technically real but semantically wrong content — worse than an honest empty state, because it would look like a business timeline while actually showing security events (or, for most employees on most days, nothing, misleadingly implying "no activity" when the real story is "no security-relevant events").

**Files:** `apps/roster-web/src/components/profile/ActivityTab.tsx`, `services/api/src/permission/audit-queries.ts` (or wherever `queryAuditLog` lives), `packages/schema/src/audit.ts`, `packages/schema/src/audit-query.ts`

**Ruling.** **Closed 27 September 2026 by ruling.** Activity is not wired to the audit log. It renders its already-correct empty state from a real (currently nonexistent) per-employee business-event source — there is none yet, and none is invented. A future feature that wants to populate this tab (performance reviews, status-change history, or similar) is the one that defines what "activity" means for this screen and builds its own event source; `VRS-F002`'s Out of Scope section gains a line saying so explicitly, so a future reader is not tempted to reach for the audit log the way this brief nearly did.
