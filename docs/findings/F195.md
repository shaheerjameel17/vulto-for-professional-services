### F195 — "four canonical graph records" for workspace creation is actually five

Surfaced building FDN-85 Stage 2, against `VPS-F001` G05's own text and the executable graph.

`VPS-F001` G05, the Workspace-creation section and the `workspace.create` API contract all name **four** atomic graph records: the Workspace node, the WorkspaceMembership node, the `membership_of` edge (WorkspaceMembership → User) and the `membership_in` edge (WorkspaceMembership → Workspace). Implementing the projection showed a fifth is unavoidable: FDN-92's materializer refuses an edge whose endpoint node is not itself materialized (its dangling-endpoint refusal, proven in FDN-92 Stage 3), `membership_of`'s endpoint is the founding Owner's `User` node, and the per-workspace Loro document is **empty** at creation time. `VPS-F001` G01 creates the User node "on account creation," but the graph is per-workspace and that node has never been written into *this* workspace's graph. So the User node is part of the atomic set, not a precondition the projection may assume.

**Closed by FDN-85 and source correction.** The projection command builds one Loro delta carrying all five records — Workspace / display (unscoped, no `workspace_id`), User / record (unscoped), WorkspaceMembership / record (workspace-scoped, carrying the role as history), `membership_of`, `membership_in` — so "all four or none" is satisfied at the graph layer by a single atomic commit (authorization fails → nothing; materialization fails → nothing durably flushed). The User write is an idempotent upsert keyed by the shared account id, harmless if the node is already present from another workspace's projection. `VPS-F001` G05, the Workspace-creation section and the `workspace.create` contract now say five. Evidence chain: FDN-85's Q1–Q7 decision memo (Q1), the Stage 2 checkpoint, and the real-stack browser proof (`services/api/browser-tests-device-store/workspace-membership-projection.spec.ts` — the WorkspaceMembership node and both edges query back after a genuine close, reopen and re-materialization).
