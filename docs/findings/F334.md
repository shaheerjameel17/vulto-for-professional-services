### F334 — the schema permits invalid TOIL and Earned combinations

**Found while:** briefing Stage 27 (`VRS-F018`), 26 September 2026, by checking the spec against the code before writing the brief.

The spec makes `TOIL` a leave type with `accrual_method: Earned` and says Earned exists for TOIL specifically, but the policy schema as written permits an `Earned` annual-leave type, or a `TOIL` type with `Immediate` accrual, and `employment_type_scope` adds `All` to the four real `Employee.employment_type` values (`FullTime`, `PartTime`, `Contractor`, `Intern`).

**Files:** `packages/schema/src/employee.ts`, `docs/Vulto_Specs/VRS-F018_Leave_Policy_Engine.md`

**Ruling.** **Closed 26 September 2026 by ruling.** The schema enforces `accrual_method: Earned` if and only if `leave_type: TOIL` (G06), one entry per `leave_type` per policy, and `employment_type_scope` is the four employee values or `All`. Until Stage 28, an `Earned` type is accepted as configuration and its balance is an explicit `entitledYtd: 0` with a `notes` entry saying earned accrual is not built yet, never a silent zero.
