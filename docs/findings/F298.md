### F298 — `search.query` cannot be both entirely local and `adHocSearch`'s unmodified result

`VPS-F002`'s API contract returns `skillMatches?` from `search.query` — "exactly `skillMatcher.adHocSearch`'s return shape, passed through unmodified" — from a function documented as "Entirely from the local index. No network request", and its acceptance criteria and non-functional requirements repeat the claim that skill delegation "resolves from the local index with no degradation" offline. But `skillMatcher.adHocSearch` (`services/api/src/router.ts`, `protectedProcedure`, running `adHocSearch` in `skill-matcher-queries.ts` under the caller's own principal) has been a server-side authorized read since F286 (Stage 21), which retired the ad-hoc mode's local scan and its per-keystroke latency budget explicitly; it also reads `has_skill` proficiency and bench availability under interceptor rules no local query reimplements (F293).

**Closed by direct precedent — F286's own ruling, and F199's own scoping of this same spec (a server-backed group that degrades to `requires-connection` with **Retry**, never blocking or reordering the local results). No founder consultation needed.** The skill-match group is a server-backed group: `search.query` (local) stays exactly what its comment says and drops `skillMatches`, gaining a `skillMatched: boolean` — true when at least one indexed `Skill` row matches the text, computed from the complete match set before any per-group limit — and the palette calls the existing `skillMatcher.adHocSearch` unmodified, in parallel, only when it is true. Proficiency ordering, availability filtering and Ghost inclusion therefore remain that feature's logic and are never duplicated (G04), and the acceptance criterion "identical in content and ranking to `VRS-F013`'s own result" holds trivially because it is the same call. Offline, that group alone renders `requires-connection`, the same treatment the server-backed protected-name group already had. No server code changes this stage.

**Status: closed.**
