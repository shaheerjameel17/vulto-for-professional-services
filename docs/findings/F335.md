### F335 — where a TOIL accrual lives (RST-60): an append-only Tier 0 ledger

**Found while:** the founder's decision on RST-60, 27 September 2026, after Stage 27 merged.

F327 left open where a TOIL accrual lives, because the only record of an overtime approval is the Tier 2, Manager-restricted `TimesheetAnomalyFlag`, while TOIL is specified as a live, offline, Tier 0 balance with no new node type. Option (a) was a small Tier 0 accrual record; option (b) a server-derived, online-only figure.

**Files:** `docs/Vulto_Specs/VRS-F018_Leave_Policy_Engine.md`, `packages/schema/src/registry/nodes.ts`

**Ruling.** **Closed 27 September 2026 by founder decision: (a), as an append-only ledger.** A new Tier 0 node type, `LeaveLedgerEntry`, written only by the server, in the same transaction as the flag clearance, and never edited. Each entry carries the days granted, the `LeavePolicy` version that priced it, its expiry and an opaque source reference; it carries nothing of the Tier 2 record (hours, week, reason, note). A correction is a compensating entry, never an edit. Option (b) was rejected: a derived figure re-prices past accrual when policy changes, is online-only, and makes the server read protected data on every balance query. Edge metadata was rejected as unqueryable, unauditable hidden state. The spec's "no new node type" is superseded for this one type. The same ledger later carries manual adjustments and reversals and can carry `VRS-F019` debits.
