### F327 — the overtime half of VRS-F018 cannot be built as specified and is split to Stage 28

**Found while:** briefing Stage 27 (`VRS-F018`), 26 September 2026, by checking the spec against the code before writing the brief.

`VRS-F018` is one feature but two stages of work, and its overtime half cannot be built as specified. `S05` says approved overtime accrues TOIL, computed live (G04), as a leave type with `accrual_method: Earned`, with "no new node type", visible to the employee as a Tier 0 balance. But the only record that an overtime approval happened is `VRS-F010`'s `TimesheetAnomalyFlag`, which is fixed `Manager-restricted` Tier 2 (F312): the employee cannot read it, no device holds it, and a live balance computed from it can only be computed on the server with a system principal, which contradicts the Tier 0, offline-capable balance the spec promises. The spec also adds a `clearance_outcome` field to a flag whose clearance fields are protected, and `overtime.approve(flagId, loggedHours, expectedHours)` takes hours the caller could not have read.

**Files:** `docs/Vulto_Specs/VRS-F018_Leave_Policy_Engine.md`, `docs/Vulto_Specs/VRS-F010_Timesheet_Speed-Run.md`, `packages/schema/src/registry/nodes.ts`

**Ruling.** **Closed 26 September 2026 by ruling: split, and the overtime half is deferred behind a founder decision.** Stage 27 builds the policy layer and the accrual engine for `Immediate`, `Monthly` and `Annual` (S01, S03 without Earned, S04, and policy resolution); Stage 28 builds S05 once the founder chooses where a TOIL accrual lives. The options, for that decision: (a) a small Tier 0 accrual record (a new node type, contradicting the spec's "no new node type", or metadata on an existing Tier 0 edge) written when the flag is cleared, so the balance stays live, Tier 0 and offline-capable; or (b) the balance's TOIL part computed on the server from the protected clearance with a system principal and returned as a derived figure, keeping the flag the single source but making TOIL online-only. The reviewer's recommendation is (a). Nothing in Stage 27 depends on the answer.
