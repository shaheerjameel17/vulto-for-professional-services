### F212 — device-store-browser tests the retired local-first stack

**Found while:** closing Stage 6, when the slow lane could not go green: `browser-suites (device-store-browser)` has failed on every `main` run since the Stage 4 merge (for example runs 35580319641 and 35582423261) and on `stage-6-sync`.

**What it is.** The suite (`services/api/playwright.device-store.config.ts` and its specs, run through `pnpm test:device-store-browser`) exercises the device store, the Rust sync-engine relay and the sealed store, all of which F199 retired. Nothing in the new architecture can make it pass.

**Ruling (founder, 21 September 2026).** Disable the job now, without recording an exception and without merging on a red check: `device-store-browser: device-store-browser tests the retired local-first stack; disabled at Stage 6, deleted with the stack in Stage 7.` It is a stand-alone job in `slow-lane.yml` with `if: false`, no longer a row of the `browser-suites` matrix.

**What is lost while it is disabled.** The suite also carried the accessibility smoke pass (`a11y-smoke.spec.ts`). That coverage is not replaced yet; whichever stage next needs an accessibility gate must rebuild it against the new stack rather than revive this job.

**Stage 7 obligation.** Delete, together with the retired code: the `device-store-browser` job in `.github/workflows/slow-lane.yml`, `services/api/playwright.device-store.config.ts`, the device-store browser suite and its `test:device-store-browser` script, and the `FDN-93` exclusion note, which has no meaning once the suite is gone.
